# 评测结果

## 恢复基线

2026-11-25 在 Windows 上重跑冻结基线。结构校验覆盖 40 份 Markdown、44 个行为案例和 24 个触发案例。12 项行为契约的编号完整，77 项单测通过。

公开八项任务用 Chrome 157.0.8103.79 执行 64 次检查，48 次正常通过，16 个预置故障全部检出。独立 Reviewer 在新浏览器上下文复跑得到同样结果。旧综合浏览器套件以锁定的 Playwright 1.57.0 执行 28 次检查，14 个参考实现通过，14 个故障被检出。

这些任务使用浏览器和合成内存状态。无真实生产持久化、视觉盲评或真人任务完成证据。[运行配置与哈希](../../bench/evidence-v06/recovery-rerun/verification.json) [64 次原始结果及截图](../../bench/evidence-v06/recovery-rerun/results.json)

## 本地模型试跑

2026-11-25 使用 Ollama 0.21.0 和本机 Qwen 3.5 9B Q4，固定随机种子与预算。在四个独立任务包中执行同一公开搜索任务，每组一次。引导材料显式注入，未测试客户端自动触发。

| 组别 | Chrome 判分 | 输入 Token | 输出 Token | 秒 |
| --- | --- | ---: | ---: | ---: |
| A 无技能 | PASS | 534 | 777 | 41.906 |
| B 通用 UX 清单 | FAIL | 642 | 857 | 35.641 |
| C 冻结 v0.6.0 | FAIL | 3,870 | 1,379 | 61.812 |
| D 候选 v0.6.1 | PASS | 3,870 | 992 | 50.594 |

B 移除原有可访问名称，使四个验收路径找不到搜索字段。C 在两个视口的异常路径仍显示过期结果。A 和 D 各通过四个路径。D 总 Token 为 A 的约 3.7 倍。本题 C 和 D 注入的提示仅在版本号上不同，单次结果无法归因于规则改进。其余预备任务的 28 格仍未执行。没有任务级区间，也没有正式模型增益或使用成本结论。
