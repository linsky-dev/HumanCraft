# 公开范围核验

交接外层清单 10 项逐项复算 SHA-256，原始发布清单 3 项交叉核对，3 个内层 ZIP 通过 CRC。原书及私人研读报告只校验字节哈希。交接目录和私人材料没有解压到 Git 仓库。完整源码 ZIP 408 项与恢复提交同名 Git 对象逐字节一致。

恢复范围内的历史提交和最多两层归档使用 Gitleaks 8.30.1 脱敏扫描，未命中密钥检测。另检查历史路径、原书及私有文件名、常见私人邮箱及主目录路径，未命中。历史浏览器失败证据仍含合成夹具的运行路径，属于公开夹具的诊断信息。开源素材及归档的法律权利由维护者确认。

历史 GitHub Actions 配置使用只读内容权限。候选版将 Actions 固定到核实的提交，checkout 不保留凭据。浏览器判分仅适用于受控内容，独立实验仍需分开模型与判分环境。
