# Security

The core skill is Markdown guidance and optional local utilities. It is not an authorization service, security sandbox or compliance certificate. Benchmark submissions are untrusted code; use a separate restricted environment, no credentials, no production data, and appropriately bounded filesystem and network access. A browser context alone is not a security boundary.

Please report suspected vulnerabilities privately through the repository maintainer's GitHub security reporting feature if enabled, or privately contact the maintainer to arrange a disclosure channel. Do not post exploit details or secrets in public issues. Include affected version, reproduction and impact with sanitized data. The public preview does not promise a specific response time.
