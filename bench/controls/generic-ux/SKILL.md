# Generic UX checklist
Understand the user goal and existing workflow. Make navigation intuitive, use clear labels, keep actions consistent, provide immediate feedback, prevent errors and offer recovery. Keep the interface accessible, responsive, and visually coherent. Use the existing design system. Cover loading, empty, error and success states. Preserve existing behavior, avoid unnecessary changes, and run available tests before delivery. Report limitations honestly.
