# Contexts: adapt rather than apply a universal visual recipe

| Context | Prioritize | Stress case |
|---|---|---|
| Desktop productivity | Stable layout, search, keyboard, file paths, offline behavior, safe updates | Interrupted import, unavailable drive |
| Enterprise/public administration | Accurate scope, audit, role boundaries, traceability, efficient batch work | Similar names, conflicting rules, permission revoked |
| Consumer/mobile | First-use clarity, touch, relevant defaults, low bandwidth | One-handed use, interrupted onboarding |
| Dashboard | Decision-first information, units, freshness, accessible charts, drill-down | Missing data, misleading aggregation |
| AI assistant | Capabilities, evidence, control, correction and bounded autonomy | Wrong recommendation, tool failure |
| Service journey | Cross-channel continuity, ownership, wait clarity and handoff | Lost handoff or inconsistent instructions |
| High-stakes tools | Proportionate friction, identity verification, audit, independent review | Misinterpretation or wrong-target action |

Never use a domain label as proof of user needs. Follow actual legal, security and platform requirements and flag those needing specialist verification. For private/on-device systems, do not introduce telemetry or cloud services without authorization. For existing products, preserve validated workflows and avoid unrequested wholesale rewrites.
