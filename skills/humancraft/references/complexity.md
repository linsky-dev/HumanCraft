# Complexity: make necessary complexity understandable

Inventory irreducible business rules vs accidental complexity (duplicate entry, ambiguous names, unnecessary navigation, implementation jargon, manual coordination). Move routine work to reliable system behavior without concealing material consequences. Modularize by activity rather than backend tables. Make prerequisites, sequence, current state and ownership explicit. Offer an accessible basic path and discoverable expert controls; keep keyboard shortcuts and batch operations as appropriate.

Service blueprint: actor, touchpoint, visible action, backstage work, owner, dependency, failure, recovery. Check handoff consistency across screens, devices, people and offline/online boundaries. A locally easy form can still create an exhausting service.

Waiting and asynchronous work: communicate what is happening and why; show factual progress or an indeterminate state, calibrated estimates only when grounded, fair queue rules where relevant, ability to leave/resume/cancel where feasible, and clear completion. Provide useful parallel tasks only if they don't distract from critical monitoring. Never invent progress percentages or countdowns.

Social cues: use shared patterns, examples or aggregate signals only when authentic, privacy-preserving and relevant; never fabricate popularity. Provide contextual help at the moment of need, then accessible full documentation for real complexity. Good defaults should be safe, reversible and explicit about meaningful consequences.

Verify: compare end-to-end time and rework, not only click count; test beginners and experts; simulate interruption between modules, handoff failures, simultaneous edits, partial completion and resuming a long task.

## Advanced behavioral checks
Map visibility boundaries: owner, visible state, and escalation. Disclose material queue reasons and priority policy; avoid intentionally inflated estimates or deceptive waiting. Offer optional useful activity. See HC-B04/B05/B09. [Contracts](behavior-contracts.md).
